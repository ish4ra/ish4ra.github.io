# Ishara Lakshan — Portfolio

Personal portfolio and interactive GitHub Pages site.

**Live site:** https://isharalakshan.xyz

## About

This repository contains my personal portfolio, project showcase, GitHub activity visuals, and interactive UI experiments.

The site is intentionally built as a lightweight static project so it can be hosted directly with GitHub Pages.

## Highlights

- responsive personal portfolio
- project showcase
- custom motion / scroll effects
- GitHub-style activity visuals
- interactive snake mini-game
- leaderboard components
- custom domain through GitHub Pages

## Tech

- HTML
- CSS
- JavaScript
- GitHub Pages

## Repository structure

```text
index.html              Main portfolio page
app.js                  Core site interactions
motion.js               Motion and scroll behaviour
motion.css              Motion-related styling
snake-core.js           Snake game logic
snake-engine.js         Snake runtime / engine
leaderboard.html        Leaderboard view
leaderboard.js          Leaderboard behaviour
leaderboard-motion.js   Leaderboard motion effects
leaderboard.css         Leaderboard styling
icons/                  Local icon assets
CNAME                   Custom-domain configuration
```

## Deployment

The site is deployed from this repository with GitHub Pages and uses the custom domain:

**isharalakshan.xyz**

Changes to the live site are made through the site source files. This README is documentation only and does not change the rendered portfolio.
