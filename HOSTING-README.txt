ISHARA LAKSHAN PORTFOLIO - HOSTING FILES

This is the complete editable static website: HTML, CSS, JavaScript,
social icons and the resume PDF. No npm install, build step, backend,
API key or ChatGPT account is required to serve these files.

1. Extract this ZIP.
2. Upload index.html and all accompanying files/folders to the public
   root of your static hosting service. Keep the icons folder intact.
3. Make sure index.html is directly in the hosting root, not nested
   inside an extra portfolio folder.
4. Test the host's provided URL before attaching your custom domain.
5. Configure isharalakshan.xyz using the DNS records supplied by your
   chosen host. This ZIP does not change DNS or domain auto-renewal.
